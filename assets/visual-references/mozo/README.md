# もぞ 公式ビジュアルリファレンス

このフォルダは、AIニュース動画で使用するキャラクター「もぞ」の正解見本を保管するための場所です。

## Canonical reference

- `mozo-character-reference.png` — もぞの公式キャラクター見本。動画・静止画・プロンプト・レンダラー実装では、この画像を最優先の視覚リファレンスとして扱うこと。

## 使用ルール

- 白くシンプルな体。
- 黒目のみで白目は描かない。
- 左右の目の大きさを明確に変える。
- 手描きのラフな線と、少し不器用でゆるい雰囲気を保つ。
- 茶色の小さなリュック、やさしい緑の手を基本要素とする。
- 表情は控えめ。過度にアニメ的・3D的・完璧に整った造形へ寄せない。
- AIニュース動画では、説明・調査・案内などの補助役として使い、ニュース内容より目立たせすぎない。

文章仕様と画像の印象が衝突する場合は、キャラクターの見た目についてはこのフォルダ内の公式リファレンス画像を優先します。
