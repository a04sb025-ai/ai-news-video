# OpenMontage用 AIニュース動画 冒頭3秒・ビジュアル仕様

## 目的

最初の3秒でスクロールを止め、スマホ一覧でも一瞬でニュースの意味が伝わる状態を完成基準とする。冒頭3秒は通常の説明ページではなく、**動画内に埋め込まれた完成サムネイル**として設計する。

正本は `docs/ai-news-video-visual-spec.md`。本書はOpenMontage／レンダラー実装時の冒頭要件を抜き出したものとする。

## 1. 基本仕様

- 1080×1920 / 9:16 / 30fps
- 0.000〜3.000秒をサムネイルウィンドウとする
- 0 / 1 / 2 / 2.967秒の全てで主要要素を完全表示する
- fade-inで0秒を未完成にしない
- 音声なしでも主題が分かる

## 2. 冒頭に表示するもの

原則として次の4要素だけに絞る。

1. 最大2行の巨大見出し
2. ニュース内容に直結する主ビジュアル1つ
3. 小さな `AI NEWS` 等のeyebrow
4. 控えめな `AIツールウォッチ` / もぞのブランド要素

**0〜3秒では表示しないもの:** `support_text`、全文字幕、長い補足、もぞの長い吹き出し、複数アイコンによる説明図。これらは3秒以降の本編ページで表示する。

## 3. thumbnail_style A / B / C

### A — 号外・新聞見出し風

危険、規制、セキュリティ、障害、論争、緊急性のある問題提起に使用する。太い見出しと警戒アクセント、実際の対象関係が分かる1場面で緊張感を出す。警告アイコンの寄せ集めや根拠のない恐怖演出は禁止。

### B — 雑誌表紙・編集特集風

トレンド、業界変化、注目テーマ、AIエージェント、モデルの位置づけ、「なぜ重要か」系に使用する。強い編集的ヒーロー画像と大見出しを中心にする。企業説明資料やインフォグラフィックにはしない。

### C — シンプル断言ポスター風

新機能、性能、記憶、コンテキスト、速度、音声、UIなど直感的な利用者メリットに使用する。見出しを最も短く・大きくし、主役1つと余白で成立させる。

## 4. 見出し

- 最大2行
- 1行9文字前後を目安
- 記事タイトル全文を縮めただけにしない
- 抽象語や専門用語単独で終わらない
- 結論、驚き、違和感、危機感、明確な利益のいずれかを伝える
- 元情報より強く断定しない

例:

- `AGENT` → `AIが勝手に動く時代へ`
- `LONG CONTEXT` → `AIが忘れにくくなる`
- `30Bって何？` → `なぜ今30B級なのか`

## 5. 主要ビジュアル

- 1画面1主役
- 人物、製品、対象、出来事、Before/Afterなど認識しやすい場面を優先
- 背景より主題を大きくする
- 画像生成時点で上半分に見出し用の余白を確保する
- AIチップ、盾、ロボット、フローチャート、矢印を並べただけの汎用AIコラージュは禁止
- 生成画像内の文字・数字・ロゴ・透かしは禁止

## 6. 3秒以降

サムネイルウィンドウ終了後は通常の解説ページへ移行し、必要な `support_text` とナレーション字幕を表示する。サムネイルを強くするために、本編のアクセシビリティや字幕を削除してはならない。

## 7. QA

0 / 1 / 2 / 2.967秒を抽出し、以下を確認する。

- 小さく表示しても見出しが即読できる
- 何のニュースか分かる
- A/B/Cの選択が内容に合う
- 主ビジュアルが1つに絞られている
- 小さな本文・全文字幕がない
- 汎用AIネオン図解になっていない
- 続きを見たくなるが、誇張していない
- ブランド統一感はあるが、過去動画と同じ画面には見えない

不合格なら見出し、構図、主ビジュアル、A/B/C選択、情報量を修正して再レンダリングする。事実性・音声・decode・black-frame等の既存ゲートは緩めない。
