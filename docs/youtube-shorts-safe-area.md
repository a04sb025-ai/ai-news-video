# YouTube Shorts UI safe area

AIツールウォッチの日次 9:16 動画（1080×1920）では、YouTube Shorts のアプリUIが映像へ重なる前提で重要テキストを配置する。

## 1080×1920 の数値契約

重要テキストの共通除外域は次のとおり。

- 上: 160px（8.3%）— 戻る・検索など上部UIを避ける。
- 左: 72px（6.7%）— 端末差とクロップの余白。
- 右: 192px（17.8%）— 本編下半分では、いいね・コメント・保存・共有の縦レールを避ける。
- 下: 576px（30.0%）— チャンネル名、説明、公開状態、共有UI、下部ナビゲーションと重なるため、重要テキストを置かない。

したがって本編の重要テキスト用ハードセーフ矩形は `x=72..888, y=160..1344`。実際の本編コピーはさらに狭い `x=72..888, y=742..1328` に収める。

冒頭0〜3秒は下側のアクションUIより上に置くため、見出しは上部専用レーンを使用する。ただし `y < 160` には重要テキストを置かない。

## レイアウト契約

本編の主ビジュアルは原則 `y=8%..36%` に重要部分を置く。`y=38%..70%` はラベル・見出し・補足・字幕のための低ディテール帯にする。`y=70%..100%` はYouTube UIの被りを前提とした領域で、進捗線など失っても意味が変わらない装飾以外の重要情報を置かない。

右側についても、本編コピーの右端は `x=888` を超えない設計とする。背景画像は全面を使ってよいが、右下に重要な顔・数字・ラベル・比較対象を置かない。

## QA

レンダーmanifestへ safe-area のpx値と比率を記録し、テストで固定値と本文の座標を検証する。公開品質の判定では、文字サイズを小さくして領域へ押し込むのではなく、位置を上げる・文章を短くする・ページを分ける順で修正する。
