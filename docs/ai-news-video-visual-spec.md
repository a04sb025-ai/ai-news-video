# AIニュース動画 標準ビジュアル仕様

## 1. 正本・コンセプト

本書を `daily_story` の標準ビジュアル仕様とする。シリーズの約束は **「もぞが、難しいAIニュースをやさしく噛み砕いて解説するAIニュース動画」**。1080×1920、9:16、30fps、スマホ最優先、1画面1メッセージとし、ニュース感・テック感・親しみやすさを両立する。事実、数字、固有名詞、意味を変えず、記事本文の転載や読み上げではなく、何のニュースか→何が変わったか→なぜ重要か→誰に影響するか→必要な仕組み、の順で短く視覚化する。

既存の事実・音声・媒体QAは本書より優先して維持し、合格のために閾値を緩めない。

## 2. 冒頭3秒は完成済みサムネイル

- 0.000秒から、上部の大見出し、中央の情報カード、下部のもぞと吹き出しを完全・不透明に表示し、2.967秒（30fpsのopening最終フレーム）まで維持する。
- 主要要素のfade-in / fade-out、途中退場、読み終える前の切替を禁止する。背景画像もopening中は静止を標準とする。
- 0 / 1 / 2 / 2.967秒のどこを静止画化しても、音なしでニュースの意味が通じること。
- 見出しはverified headlineを意味変更せず動画向けに短く用意し、1〜3行、白の極太字、黄〜オレンジの太い縁、暗い影、高コントラストとする。実装はさらに厳しい最大2行・各18文字・112pxを採用する。
- 見出しは左右90px、上160px、下260pxのsafe areaを侵さない。記事タイトル全文、小さい文字、細字、長い説明を禁止する。

## 3. 固有の背景言語

黒・濃紺・深い青を面の基調に、ゴールド／オレンジ、紫／ラベンダー、青を少量だけ使う。疎な回路、光点、ノード、細線、幾何、緩いグリッド、波形、柔らかな光、半透明パネルを組み合わせるが、背景は文字とニュースカードより後景に置く。

特定のShorts、クリエイター、媒体、公式サイトUIを模倣しない。大量の0/1、Matrix rain、ネオン過多、サイバーパンクの定型、ロボット、光る脳・球、ストック風企業絵、記事サイトのスクリーンショット、読める偽UIを禁止する。生成画像にも文字・数字・ロゴ・透かしを入れない。

## 4. 中央カードとテンプレート

カードは白／薄灰／薄紫の独自UIで、説明を詰めず図だけで概意が分かるようにする。

### A — 仕組み解説

疑問または結論見出しと、`入力 → しくみ → 変化` の3段フロー。吹き出しは「ここがポイント」。仕組み、理由、方法、透かし、検出などの解説に使う。

### B — 新機能・新発表

強い結論と、ブラウザを複製しないサービス／発表カード。吹き出しは「何が変わる？」。公開、正式発表、新機能、提供開始、リリースなどに使う。

### C — 比較・変更

結果見出しと、明確な `BEFORE / AFTER` 2カラム。吹き出しは「ここが違う」。比較、従来との差、変更、改善、刷新、アップデートなどに使う。

自動選択はverified briefの headline / hook / summary / pointsだけを対象とする。比較語を最優先、次に仕組み語、次に発表語を判定し、該当なしは説明に安全なAとする。選択は表示形式だけを変え、事実を追加しない。

## 5. もぞの固定アセット仕様

もぞは全 `daily_story` の標準解説役で、左下（内容に応じ右下可）に置き、中央カードや見出しより目立たせない。

- ラフな手描き感、シンプルな白い体、左右非対称で少し不器用な輪郭。
- **白目は禁止**。目は濃色の塗りだけで、左右の大きさを必ず変える。
- 控えめな表情、小さな指差し程度。必要時のみ小さなリュック。
- アニメ美少女・美少年、リアル3D、派手な表情、別キャラクター化を禁止する。
- 生成画像にはもぞや代替マスコットを描かせず、レンダラーの固定ベクターを重ねる。
- クリーム／白／薄ベージュの吹き出しを用い、「ここがポイント」「何が変わる？」「ここが違う」など一言だけ表示する。

## 6. 本編とモーション

3秒以降は、結論→理由→仕組み→ユーザーへの影響の順を基本に、「つまり」「何がすごい？」「誰に関係ある？」などで整理する。専門語や長文を並べず、字幕は最大2行・各18文字を目安にする。軽いスライド、ポップ、順次表示、小さなジェスチャー、緩いズームだけを許可し、激しい回転、速いズーム、点滅、過剰なtransitionを禁止する。

## 7. QA・公開ゲート

story validation、voice QA、headline semantic match、opening QA、完全decode、black frame、MP4生成、1080×1920・10〜15秒・音声、25MiB以下、`auto_publish_ready` を必須のまま維持する。opening QAではさらに次を機械検査する。

- `ai-news-visual-v1`、A/B/C、標準キャラクター `mozo`、0〜3秒静止契約がstoryに記録されている。
- 0 / 1 / 2 / 2.967秒で、見出し、見出しパネル、中央カード、もぞ、吹き出しの各領域が可視で、フレームが黒／空でなく十分なコントラストを持つ。
- verified headlineとのsemantic match、最大2行・各18文字、112px（最低56px）、safe areaを満たす。

機械QA後も4枚をスマホ相当で目視し、文字サイズ、コントラスト、背景干渉、もぞの造形と非干渉、1画面1メッセージ、単独サムネイル成立を承認する。生成画像のないfallbackは技術QAを継続できるが `auto_publish_ready` にはしない。

## 8. NG一覧

既存人気動画のコピー、特徴的背景の再現、Matrix風0/1、ネオン過多、一般的な生成AI美少女／美少年、文字だらけ、小字幕、長いタイトル、白目のある／毎回変わるもぞ、opening主要要素のfade、3秒以内の消失、記事画面を貼るだけの映像を禁止する。
